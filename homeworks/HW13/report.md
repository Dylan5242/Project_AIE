# HW13 – токенизация текста, инференс BERT и базовый fine-tuning для классификации

## 1. Кратко: что сделано

- Использовался emotion, так как он содержит размеченные твиты на английском языке с шестью базовыми эмоциями, что идеально подходит для задачи многоклассовой классификации текста.
- nlptown/bert-base-multilingual-uncased-sentiment.
- Продемонстрирована работа WordPiece токенизатора, разбиение на подслова (subwords), использование специальных токенов [CLS], [SEP] и механизмы padding/truncation.
- Готовая модель для Sentiment Analysis (звезды 1-5) неплохо определяет общую полярность, но не способна различать специфические эмоции.
- Какой результат дал fine-tuning.
